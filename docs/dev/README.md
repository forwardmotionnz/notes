# Development records

How Notes has been built, kept for anyone curious or picking up the work.
None of it is needed to use Notes or to contribute.

- [MVP.md](MVP.md): the ledger. Every item from the first version onward,
  with its plan, the evidence it was done (tests, screenshots, commits), what
  each independent review found and how it was fixed, and the decisions made
  along the way.
- [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md): the checks run on real
  GitHub accounts and devices before the first release.
- [`.claude/commands/gauntlet.md`](../../.claude/commands/gauntlet.md): the
  process each item goes through (test first, build, break each safeguard on
  purpose, independent review, screenshots, docs), written for the AI coding
  agents that have done much of the work.
