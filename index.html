Now, a place for your notes

Your notes live in a GitHub repository of your own. Make one, then let Padgit use it.

  1. 1. Create a repository On GitHub, in a new tab. The name and Private are filled in: press Create repository. Already have one to use? Go to step 2.
  2. 2. Let Padgit use it Choose Only select repositories, pick yours, then press Install (or Save).

Then come back here, to this tab or the Padgit app: it notices by itself.
