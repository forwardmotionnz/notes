Padgit

Notes on any device, kept as Markdown files in your own GitHub repository, which AI tools you connect can read. It can read and write files only in repositories the app is installed on, which you choose. Your notes stay there, though whoever runs this copy's GitHub App can reach them too. Privacy

Look around first

No GitHub account? Make one, free, then come back here to sign in.

How it works
  1. Sign in with GitHub.
  2. Choose, or create, one private repository for your notes.
  3. Write. Every save is a plain file in that repository, which you can also open in Obsidian or on GitHub.

Now, a place for your notes

GitHub keeps your notes in a repository: a private folder of files, with a history of every change. Make one, then let Padgit use it.

  1. 1. Create a repository On GitHub, in a new tab. The name and Private are filled in: press Create repository. Already have one to use? Go to step 2.
  2. 2. Let Padgit use it Choose Only select repositories, pick yours, then press Install (or Save).

Then come back here, to this tab or the Padgit app: it notices by itself.

Only repositories the app is installed on are listed. Choose repositories (on GitHub, in a new tab; this list updates when you come back here)
